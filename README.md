# 📅 Mini Calendar Using HTML, CSS & JavaScript

This project is a simple Mini Calendar App built using HTML, CSS, and JavaScript. It dynamically displays the current day, date, month, and year using JavaScript's Date Object.

## 🚀 Features
- Displays current day, date, month, and year
- Dynamic date updates
- Responsive UI
- Beginner-friendly project

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
