📅 Mini Calendar Using HTML, CSS & JavaScript

This project is a simple Mini Calendar App built using HTML, CSS, and JavaScript.
It displays the current date, day, month, and year dynamically using JavaScript's Date Object.

The calendar updates automatically based on the user's system date and is useful for understanding how JavaScript handles real-time date operations.
